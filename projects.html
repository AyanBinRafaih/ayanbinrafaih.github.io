AgentFlock

Active
  • Python
  • TypeScript
  • PostgreSQL
  • Apache Kafka
  • Docker
  • Kubernetes
  • Distributed multi-agent platform with 6 independently deployable microservices: an API gateway, an orchestrator, and 4 specialised agents (planning, research, writing, review) communicating asynchronously over an Apache Kafka event bus with full event sourcing.
  • DAG-based task scheduler in the orchestrator uses an LLM (Groq Llama 3.3 70B) to decompose research tasks into dependent subtasks, dispatching agents dynamically as soon as their dependencies resolve.
  • Deployed to a 10-pod Kubernetes cluster with GitHub Actions CI/CD (lint / test / build on every push) and a React dashboard for real-time task tracking and PDF report generation.

Limit Order Book (LOB)

In progress
  • C++20
  • CMake
  • GoogleTest
  • Google Benchmark
  • GitHub Actions
  • Limit order book matching engine built from scratch in C++20: price-time priority matching, multi-level execution, partial fills, and O(1) cancellation via iterator-indexed order lookups.
  • Low-latency features including cache-line-aligned order representations, RDTSC-based timestamping, LFENCE serialisation, and runtime cycle-to-nanosecond calibration.
  • 11 unit tests covering correct matching, quantity conservation, cancellation, and partial fills.
  • Currently building a lock-free SPSC ring buffer and per-operation latency-distribution analysis (tail latencies, distribution fits).
