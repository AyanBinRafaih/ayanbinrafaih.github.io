This folder holds image assets for the site.

Add your photo here, named exactly:

    profile.jpg

A square image works best (roughly 800x800px). Until this file is added,
the homepage automatically shows a small placeholder box instead of a
broken image — once you add profile.jpg, it will appear automatically
with no other changes needed.

You can add more images here later (e.g. a different crop for a future
og:image / social preview card) — just keep this folder name (assets/img/).
